# Keep a handover current

As soon as you have oriented yourself, create `HANDOVER.md` in the return directory named in your opening instructions. Write for someone who might take over now. Tell them where the work stands, what is in motion or waiting on someone, and the next useful step. Point to a file, command or decision when it would help them pick up the work.

Keep that same document current throughout the episode. When a check settles a question, a dependency clears, or the next step changes, revise the affected passage and remove advice that has gone stale. If a sitting ends or someone takes over unexpectedly, the latest version should stand on its own.
