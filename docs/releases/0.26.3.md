# 0.26.3

This release carries the operator from a generic or repeated assignment through
one resumable closeout and a verified reading edition. Connections can name a
default recipe; explicit study plans remain optional. Empty recipe connection
lists now mean generic instructions. `finish` prints a completion summary;
scripts requiring the structured result must pass `--json`.

Codex fieldworkers can commit. The permission profile grants write access to the
checkout's .git, and native qualification uses disposable metadata within that
boundary. Research roots remain denied. Access fingerprints include execpolicy
rules. Developer launchers add read-only `--status`; reinstall and recheck them.
Capture implementation bytes and Claude's fingerprinted helpers are unchanged.

Closeout acquires supported associated native sessions and bounded document
selectors before inventory. It preserves the recording, publishes and verifies
a neutral per-run reader, and retains the latest two editions per selection.
Published recording bytes are never retrofitted. Explicit historical identities
can be left opaque to operational discovery and default reading publication;
no migration or old-analysis compatibility is promised.

Use `berman ready` for task preflight. Full maintenance verification remains
separate. Tests use synthetic sessions; adopting installations must renew native
access and changed developer launchers. Local TCP policy is unchanged: a narrower
loopback-only sandbox grant was not established by this implementation.
