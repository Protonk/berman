# 0.26.4

Fieldwork now runs through a Linux guest controller and a macOS executor.
The researcher uses `berman-research` to commission an assignment, prepare
its packet and launch or resume the worker. The executor can stage observations
while the guest is offline. A worker can return for another sitting until the
researcher declares the engagement ended.

Once the researcher ends fieldwork, one command collects the evidence,
transfers outstanding files over SSH, preserves a recording, publishes a
reading edition and verifies both on the guest.

```sh
berman-research closeout run-001 --reason 'The researcher concluded this engagement'
```

Repeat the command after an interruption. Once the guest has recorded the
ending, `berman-research closeout run-001` is sufficient. If a file in the
inventory is unavailable, closeout transfers the rest and names the gap.
Restore the file and retry, or supply the researcher's reason with
`--missing-reason` to accept the partial collection. The recording retains
that decision. Later activity can be preserved in a supplement.

Version 0.26.3 was the last release that could operate a co-located workspace.
Close any unsettled work with the version that opened it. Version 0.26.4 can
read and verify those records. To continue the study on the guest, import its
recordings and reserve its historical run numbers. Qualify native execution
on the adopting installation.
