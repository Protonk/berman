# Berman 0.26.9

This release simplifies Berman without changing how an episode runs. Episodes and records made with 0.26.8 continue to work. `berman codex-hooks` prints the same entries, so a reviewed Codex hook keeps working after an upgrade in the same environment.

## Commands and records

`berman version` is retired. `berman verify` without a record prints the same identity of the installed build and checks its files against the wheel. An episode’s `episode.json` lists the additional jobs under `jobs` only. The joined `job` field is gone. If `opening.md` no longer matches the opening recorded in `episode.json`, `start` and `resume` refuse in those terms.

## Jobs and reading

The editable `job.md` asks for a file or folder named for the job inside the return directory, so jobs selected together leave their files apart. The [reading guide](https://github.com/Protonk/berman/blob/v0.26.9/docs/records.md) lists every member of a record, including earlier transcript versions and incomplete final lines.

## Development

Development and the container check run on Python 3.13, the `python3` of Debian 13. The Lima and container files are under `development/`. [Operating guide for 0.26.9](https://github.com/Protonk/berman/blob/v0.26.9/docs/operating.md)
