# Berman 0.26.11

A resumed sitting checks its transcript against the preceding sitting’s end observation. If the session was used outside Berman or the boundary cannot be confirmed, the sitting can proceed and coverage explains why whole-transcript collection stopped. Closing uses the last attributable observation when a launcher was lost.

Unattended output stays pending while its relay is still writing. A retry or close can recover the final response and late bytes. A relay that exited before confirming its output is recorded as a coverage gap.

Return cleanup uses directory-relative file operations and checks that the library still holds the collected file before deleting its working copy. Directory reads and exports resolve their paths in the same database snapshot as their contents. Review import checks the copied source list, question and answer. Episode nesting checks run within the write transaction.

Linux working directories now carry a generic desktop-index exclusion marker. The container check verifies filename and full-text isolation for live returns and dedicated harness histories using GNOME LocalSearch.

The Linux archive preserves the program’s executable permission when it is packaged on the Mac. The extracted binary runs directly.
