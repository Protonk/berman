# Berman 0.26.8

Berman now runs on Linux alongside the project checkout and its actor. A manager can use it intermittently. Open Codex or Claude Code directly for ordinary work, or open a Berman episode to give the actor an additional job. This release replaces the 0.26.7 host/guest workflow and its record format. Start each episode in a fresh directory outside the checkout.

## Opening an episode

Run `berman help open` to see the opening arguments. `berman template` supplies two independent jobs. One asks the actor to leave occasional notes, and one asks it to keep a handover current. Choose either, repeat `--job` to request both, or supply your own instructions. The manager can inspect the opening before starting a sitting.

## Closing and reviewing

An actor can leave and resume the same episode across sittings. The manager closes it with a reason. Berman collects the actor’s return and the telemetry it could attribute to the episode in a portable record. Use `berman verify` to check a copy. To review a question, pass one or more records to `berman review` and choose a fresh directory for the reader.

The former `berman cheatsheet` command is retired. Use `berman help` for the command list and `berman help COMMAND` for the same reference as `berman COMMAND --help`. [Operating guide for 0.26.8](https://github.com/Protonk/berman/blob/v0.26.8/docs/operating.md)
