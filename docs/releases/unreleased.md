# Unreleased

Berman runs alongside a project and its actor on Linux. Open an episode with a checkout, an actor, and a file containing an additional job. The installed template includes two standing jobs. One asks the actor to add occasional notes. The other asks the actor to keep a handover current. Start and resume the actor from an ordinary terminal, then close with the manager’s reason.

This release introduces the episode CLI and portable directory record. Begin in a fresh episode directory. To read across episodes, select their records, supply a question, and choose the output directory for the reader.
