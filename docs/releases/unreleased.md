# Unreleased

Berman runs alongside a project and its actor on Linux. Open an episode with a checkout, an actor, and one or more additional jobs. Repeat `--job FILE` to give the actor several jobs in one opening. The installed template includes two independent examples. One asks the actor to add occasional notes. The other asks the actor to keep a handover current. Start and resume the actor from an ordinary terminal, then close with the manager’s reason.

This release introduces the episode CLI and portable directory record. Begin in a fresh episode directory. To read across episodes, select their records, supply a question, and choose the output directory for the reader.
