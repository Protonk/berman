Capture compatibility

The operator workflow is documented in BERMAN.md. Use it for preparation,
endings, supplements and migration. Inspect low-level recovery options with
python3 -I -B tools/fieldwork.py --help, preserving the reason and receipts.

Live hooks use berman_capture_router.py for Codex and the per-launch
berman_claude_router.py for Claude. Do not install direct collector handlers.
The router arguments bind the selected workspace and harness home explicitly.

The historical tools/capture_session.py is frozen at SHA-256 f87241a6b9506590fffa4e2a964f37bb7f7c719e508f4024661b45c57f983a99.
It remains an internal compatibility implementation, not a direct hook target.

A finalized capture and a declared engagement ending are different facts.
A copied verification receipt does not qualify a new installation.
